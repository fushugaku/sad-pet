SAD PET — приложение для компьютера

Приложение переименовано из EVIL PET Rust. Старые .evil.json продолжают
открываться; новые пресеты скачиваются как .sad.json. Библиотека IndexedDB
сохраняется на прежнем адресе http://127.0.0.1:3214 в том же браузере.

Запуск готовой сборки macOS (Apple Silicon)
  Открыть dist/SAD PET.app.
  Программа откроет панель http://127.0.0.1:3214 в браузере.
  Кнопка Quit в панели завершает звуковой процесс.

Запуск из исходников (из корня проекта)
  cargo run --release

Разработка с отдельным фронтендом и бэкендом
  ./dev.sh
  Фронтенд: http://127.0.0.1:3214, Rust API/аудио: порт 3215.
  Нужны Python 3 и Cargo. Скрипт собирает Rust в release-режиме,
  запускает оба процесса и открывает панель. Ctrl+C, SIGTERM и закрытие
  терминала останавливают оба процесса и их дочерние процессы.
  Выход любого сервиса также завершает второй. Звук включён по умолчанию.
  Фронтенд читает rust/web с диска: после правок HTML/CSS/JS обновите
  страницу. После правок Rust перезапустите dev.sh. /api проксируется
  в Rust, поэтому библиотека IndexedDB остаётся на прежнем адресе 3214.
  Перед запуском завершите готовое приложение кнопкой Quit, если оно
  занимает 3214. Чужие процессы на занятых портах скрипт не завершает.
  Другие порты: ./dev.sh --frontend-port 3314 --backend-port 3315
  Без открытия браузера: ./dev.sh --no-open

Панель работает локально. Звук рассчитывает Rust-программа и выводит
через системное устройство; в браузере находятся органы управления.
Внешние сервисы, CDN и загрузка образа .fw при запуске не используются.

Как пользоваться
  Play / Space — запуск/пауза выбранного режима.
  Open WAV или перенос файла на волну — загрузить моно/стерео WAV.
  Список над волной — 30 встроенных дорожек и ваше аудио:
  Glass sequence, Warm chords, Analog bass, Drum machine, Dusty keys,
  Vowel choir, Metallic textures, Air & rain; два записанных источника
  Matrix POV и Harvest Dawn · harp loop; ещё 20 оригинальных звуков:
  Lo-fi beat, Breakbeat, Four on the floor, Electro percussion, Dub chords,
  Acid line, FM marimba, Kalimba garden, Nylon harmonics, Music box,
  Tape piano, String orbit, Shimmer pad, Dark drone, Singing bowl,
  Resonant bells, Circuit glitches, Space transmission, Ocean swell, Vinyl dust.
  Новые звуки синтезируются локально без сторонних записей; ритмические
  лупы длятся четыре такта, BPM указан в Library. Хвосты и эхо переходят
  через границу петли. Выбор источника сохраняет настройки инструмента.
  Harvest Dawn · harp loop — луп на 42,67 с, 16 тактов при 90 BPM.
  Узнаваемое восьмитактовое вступление сверено с нотными разборами;
  две вариации исполняют арфовый синт и камерные струнные. Хвосты нот
  и реверберации переходят через границу петли без общей паузы/фейда.
  Прежний выбор восьмисекундного кавера обновляется до нового лупа.
  Автор композиции — Jeremy Soule (Oblivion, 2006). Кавер не делает мелодию
  свободной от авторских прав. Ранее сохранённые файлы IndexedDB остаются.
  Library — библиотека аудио, пресетов и WAV-рендеров. All / Audio /
  Presets / Renders фильтруют список; Search ищет по имени. Load открывает
  файл, ↓ скачивает его. Import files принимает сразу несколько WAV/JSON.
  Файлы целиком хранятся в IndexedDB браузера, включая встроенные WAV
  и заводские пресеты. Open WAV, перенос на волну и Load preset тоже
  сохраняют исходные файлы в библиотеку. Save preset и Render WAV
  сначала сохраняют результат в библиотеку, затем скачивают его.
  × переносит пользовательский файл в Trash; Restore возвращает его.
  После перезагрузки файлы остаются доступны. При новом запуске движка
  панель восстанавливает последнюю выбранную дорожку из IndexedDB.
  Библиотека принадлежит профилю браузера и адресу http://127.0.0.1:3214;
  для доступа к той же библиотеке открывайте этот адрес в том же браузере.
  Щелчок по волне / Position — положение в сэмпле.
  Протянуть по волне — выбрать зацикленный участок, в том числе на ходу.
  Маркеры IN / OUT меняют границы; поля под волной задают секунды точно.
  Стрелки на маркере: шаг 10 мс, Shift+стрелка: 100 мс; Home/End — края.
  Гранулы, Reverse, Cloud, dry и bypass читают только выбранный участок.
  Fade In / Fade Out под волной — плавное начало и конец выбранного участка
  в миллисекундах. Они работают при воспроизведении, на каждом повторе петли
  и при чтении гранулами. Настройки сохраняются для каждого файла в IndexedDB.
  0 мс отключает соответствующий fade. Длинные фейды могут перекрываться.
  Full возвращает весь файл. Save edit сохраняет обрезанную копию WAV с фейдами
  в IndexedDB и загружает её; исходник остаётся в Library. Копию можно
  скачать из результата сохранения или Library. Trim рядом с готовой
  записью открывает её для обрезки. Другой файл сбрасывает выделение.
  Freeze — зафиксировать область чтения зерен.
  Size / Reverse — длина и направление зерен.
  Grains — плотность, Pitch — высота, Cloud — разброс позиции.
  Dry / Wet смешивает исходное аудио с гранулами до фильтров. Весь результат,
  включая 100% Dry, проходит через фильтры голосов, AMP ENV и цепочку эффектов.
  В режиме микрофона Filters + FX весь вход проходит эту же обработку.
  Вращение: потянуть ручку вверх/вниз, стрелки клавиатуры;
  Shift+стрелки — крупный шаг, двойной щелчок — начальное значение.
  LFO 1–3 назначаются на параметры; есть темпо-синхронизация от 1/16
  до 8 тактов (включая 4 и 8 тактов) и follower.
  Под LFO находятся три независимые ADSR: Attack, Decay, Sustain, Release.
  ENV 1 / AMP всегда управляет громкостью каждого голоса, включая dry.
  ENV 2 по умолчанию выбран в секции Filters, ENV 3 свободен. У каждого ENV
  два дополнительных назначения с глубиной от −100% до +100%; назначение
  ENV 1 на другой параметр сохраняет его роль AMP. ENV 2 можно переназначить.
  Кривая показывает форму ADSR, индикатор справа — текущий уровень.
  Тип ENV: SAD PET (исходная ADSR, по умолчанию) или огибающие Rustias —
  RADIAS (ADSR с выбором кривой спада), Q · ADSR, Q · ADS1DS2R (Attack level,
  Decay 2, Sustain 2), Q · One Shot (проходит A–D–R даже после короткой ноты),
  Q · Loop S1S2 и Q · Loop All (циклы, пока нота удерживается). Время Q-типов
  — от мгновенного до 60 с, RADIAS — 3 мс…6 с. Старые пресеты звучат как прежде.
  Ноты клавиатуры/MIDI, Hold, Arp и Sequencer запускают все три ENV.
  Sustain-педаль удерживает их; Release продолжает генерацию зерён.
  В аккордах AMP и два фильтра рассчитываются отдельно для каждой ноты, а общие
  параметры модулируются максимальным уровнем соответствующего ENV.
  Глубина добавляется к значению ручки: если Filter полностью открыт,
  опустите его, чтобы положительная огибающая могла его открывать.
  Filters — отдельная секция с двумя независимыми фильтрами.
  Single: F1; Serial: F1 → F2; Parallel: среднее двух параллельных ветвей.
  Каждый фильтр: low pass / band pass / high pass / comb, Cutoff,
  Resonance, ENV depth от −100% до +100%, Keytrack от 0% до 100%.
  Рядом с типом выбирается ENV 1–3; по умолчанию ENV 2, глубина +35%.
  Эти связи оставляют два свободных назначения в карточке каждого ENV.
  Keytrack 100% сдвигает частоту на октаву на каждую октаву ноты;
  опорная нота C4. Учитывается MIDI pitch bend соответствующего канала.
  В Single работает F1; настройки F2 можно подготовить заранее.
  LFO и свободные связи ENV могут дополнительно управлять cutoff
  и resonance каждого фильтра независимо.
  Effects — общая последовательная цепочка до 12 эффектов.
  Выберите эффект рядом с + Add effect и добавьте его в цепочку.
  Можно использовать несколько одинаковых эффектов с разными настройками.
  Звук проходит карточки сверху вниз; ↑/↓ меняют порядок, ⏻ обходит
  отдельное звено, × удаляет его. Пустая цепочка пропускает сигнал напрямую.
  У каждого звена свой Mix и набор ручек выбранного алгоритма:
    Distortion: Drive, Tone, Bias.
    Rate reducer: Rate, Jitter, Smooth.
    Bit crusher: Bits, Drive, Dither.
    Flanger / Chorus: Rate, Depth, Delay, Feedback, Stereo.
    Binaural: Delay, Crossfeed, Width.
    Reverb: Small plate / Large plate / Room / Reverse, Predelay,
      Decay, Tone, Shimmer, Diffuse.
    Compressor: Threshold −60…0 dB, Ratio 1:1…20:1, Attack 0,1…100 ms,
      Release 10…2000 ms, Knee 0…24 dB, Makeup 0…24 dB и Mix.
      Стереоканалы сжимаются вместе, сохраняя панораму. Attack/Release
      плавно меняют усиление; Knee задаёт мягкость перехода у порога.
      Новый компрессор добавляется с Mix 100%; Mix ниже 100% даёт
      параллельную компрессию. Все ручки доступны в LFO/ENV и матрице.
      Gain Reduction под ручками показывает фактическое ослабление до Makeup
      и Mix. Шкала до 30 dB; число показывает полное значение и выше 30 dB.
      При паузе, bypass или Mix 0% индикатор равен нулю. У каждого звена
      собственный индикатор, который следует за ним при перестановке.
  Реверб можно добавить несколько раз и перемещать между другими эффектами.
  У каждого реверба собственные настройки и независимый хвост.
  При смене типа прежние положения его ручек сохраняются.
  L/C/R Delay: три времени L/C/R и уровня, Time ratio, обратная связь
  центрального отвода, High/Low damp, Trim, Spread и Mix.
  Mod Delay: времена L/R, Time ratio, Feedback, Mod depth, LFO freq,
  LFO spread и Mix; моно-вход формирует два модулируемых отвода.
  Milliseconds / Tempo sync переключает время между таблицей миллисекунд
  и музыкальными длительностями, включая триоли и пунктир. Положения
  обоих режимов сохраняются отдельно; общий BPM управляет sync-временем.
  Времена и частоты LFO взяты из таблиц RADIAS SYS 2.00 в radias-emulator.
  Максимальное время — около 2.73 s, как у его настольного DSP.
  Все ручки звеньев доступны в назначениях LFO/ENV в группах FX 1–12.
  Связь следует за звеном при перестановке. Удаление звена снимает
  его связи; временная смена типа сохраняет связи неактивного алгоритма.
  Mix звеньев, bypass, порядок, все алгоритмы и связи входят в пресет
  и WAV-рендер. Пресеты до появления цепочки получают звено с прежним
  типом, Mix и настройками Drive/Rate/Bits из прежней глубины Color.
  Прежний отдельный Reverb переносится в конец цепочки со всеми
  настройками и связями LFO/ENV; существующие восемь Color FX сохраняются.
  Совместимые назначения First reverb управляют первым ревербом в цепочке;
  назначения из групп FX следуют за конкретным звеном при перестановке.
  Mod matrix — до 8 дополнительных связей источник → параметр → глубина.
  + Add modulation добавляет строку; ⏻ обходит её, × удаляет.
  Глубина −100%…+100% складывается с положением ручки. Несколько строк
  на один параметр суммируются до ограничения диапазона.
  Источники: LFO 1–3, ENV 1–3, Velocity, Key track, Mod wheel (CC 1),
  Pitch bend, Aftertouch (channel/poly), Expression (CC 11), Random / note,
  Note gate и Input follower. LFO, bend, key track и Random — двуполярные;
  ENV, velocity, контроллеры, gate и follower — от 0 до 1.
  Нотные источники используют последнюю сыгранную ноту; Key track:
  C4 = 0, ±4 октавы = ±1. Random меняется только при новой ноте.
  ENV-источники используют максимумы огибающих активных голосов.
  Доступны все ручки эффектов, зерён и фильтров, стадии ADSR, скорость,
  sync division и глубина LFO, темп, gain/tune, параметры Arp/Sequencer,
  ноты и velocity каждого шага. Меню алгоритмов и схем не модулируются.
  Времена LFO и ритма модулируются в логарифмическом диапазоне.
  Связи генераторов пересчитываются по аудиочасам, без рекурсивного обхода.
  Прежние прямые связи LFO/ENV продолжают работать вместе с матрицей.
  Активное назначение Mod wheel в матрице заменяет прежний CC 1 → Cloud;
  без него CC 1 сохраняет старое поведение. CC 121 сбрасывает контроллеры.
  Матрица сохраняется в .sad.json и учитывается при WAV-рендере.
  На ручках видна модуляция: зелёная дуга и белая стрелка — исходное
  положение, внешняя бирюзовая дуга — диапазон, движущаяся точка — текущее
  значение DSP. Число следует за модуляцией; строка ниже показывает min–max.
  При вращении или фокусе клавиатуры число показывает базовое значение.
  Подсказка содержит базу, текущее значение и диапазон в единицах параметра.
  Учитываются матрица, прямые LFO/ENV, отдельная огибающая и keytrack фильтров.
  Маркер cutoff следует за последней звучащей нотой; диапазон keytrack
  учитывает MIDI-ноты и pitch bend. Независимые источники дают суммарную
  границу; диапазоны перекрёстной модуляции генераторов консервативны.
  Индикация не записывает модулированное значение в ручку или пресет.
  A W S E D F T G Y H U J K — хроматические ноты выбранной октавы.
  −/+ у клавиатуры или физические клавиши Z/X — октава вниз/вверх.
  Oct выбирает октаву напрямую; доступен диапазон MIDI C−1–G9.
  Диапазон и имена нот показаны на клавиатуре, октава запоминается
  в браузере. Компьютерные клавиши работают и при русской раскладке.
  MIDI использует номера нот, поступившие от внешней клавиатуры.
  В режиме Keys после игры нотами Play возвращает непрерывный голос.
  Mode → Hold note — ноты остаются звучать после отпускания клавиш;
  повторное нажатие той же ноты выключает её. Play удерживает ноту
  или аккорд из поля Notes, Clear hold снимает все удержанные ноты.
  Mode → Arpeggiator — Up / Down / Up-down / Random / As played,
  1–4 октавы, темпо-синхронизация, триоли и Gate. Hold chord сохраняет
  аккорд после отпускания клавиш. Новая группа нажатых клавиш заменяет
  предыдущий аккорд; его также можно ввести в Notes (например C4 E4 G4).
  Mode → Sequencer — до 16 шагов, темп шага, длина паттерна и Gate.
  Номер шага включает/выключает его; выключенный шаг — пауза.
  Нажмите на ноты шага и соберите аккорд на экранной, компьютерной
  или MIDI-клавиатуре. До восьми нот на шаг, можно менять октавы.
  Повторное нажатие ноты удаляет её из аккорда; Clear очищает шаг.
  Выбранные ноты подсвечены на клавиатуре. Done / Escape завершает
  редактирование, пустой шаг звучит как пауза. Выключенный шаг при
  добавлении нот автоматически включается.
  Номер шага по-прежнему включает/выключает паузу. Текстового ввода нот
  в шагах нет. Reset pattern возвращает исходный паттерн.
  Play начинает паттерн с первого шага.
  Mode → Sequencer + Arp — арпеджиатор перебирает ноты текущего шага.
  Каждый шаг начинает арпеджио заново; Direction, Rate, Octaves и Gate
  управляют перебором. Пустой или выключенный шаг — пауза.
  Модуляция Step note транспонирует все ноты аккорда вместе.
  Прежние пресеты с одной нотой в шаге загружаются как однонотные шаги.
  Step rate задаёт скорость смены аккордов, Arp rate — скорость нот.
  Общий BPM находится у секции Modulation; генерация нот идёт в Rust
  по аудиочасам, независимо от перерисовки браузера.
  MIDI выбирается справа от клавиатуры; ↻ обновляет список устройств.
  Save/Load preset — собственный формат .sad.json.
  ADSR, назначения ENV, два фильтра и схема соединения входят в пресет.
  В старых пресетах ENV 2 → Filter переносится в ENV depth первого фильтра;
  остальные свободные связи сохраняются. Пресеты до появления ENV
  получают прежние AMP ADSR и нулевую глубину огибающей фильтра.
  Render WAV — детерминированный рендер текущего сэмпла и параметров.
  Рендер начинает сэмпл, LFO и паттерн с начала; учитывает выбранный
  Mode, удержанный аккорд, шаги, паузы, скорости и Gate. Настройки
  режимов сохраняются в .sad.json. Это не запись истории MIDI-игры
  и ручного изменения параметров.
  Record рядом с Play записывает фактический стереовыход: игру нот,
  секвенсор, эффекты и движения ручек. Если транспорт стоит, запись
  запускает Play. Stop завершает запись, воспроизведение продолжается.
  Library → Recordings хранит каждую запись в IndexedDB целиком:
  WAV float32 и MP3 192 kbps. WAV / MP3 в строке скачивают нужный
  формат, Load открывает WAV как новый источник. Оба формата остаются
  доступны после перезагрузки браузера и перезапуска приложения.
  MP3 кодируется внутри приложения; FFmpeg и отдельный LAME не нужны.
  Запись продолжается при обновлении страницы; завершённая запись
  сохраняется после возвращения в панель. При ошибке доступен Retry save;
  WAV сохраняется первым. Перед Quit / остановкой dev.sh завершите запись.
  Предел одного дубля — 30 минут или 512 MB, после чего он автоматически
  завершается и сохраняется. На 48 kHz это около 23 минут.

Звуковой движок
  До 128 зерен, 9 голосов (8 нот MIDI и непрерывный голос).
  Произвольная исходная частота 8–384 kHz, индексы чтения f64.
  Два полифонических low/band/high pass / comb; цепочка из 12 эффектов,
  9 алгоритмов с независимыми параметрами, повторами и bypass звеньев.
  Каждый реверб: 4 режима, predelay, diffusion, shimmer.
  MIDI: note on/off, velocity, sustain, поканальный pitch bend,
  all notes/sounds off, program change (5 встроенных пресетов).
  CC 7 — громкость, CC 1 — cloud, CC 39 — Mix первого эффекта,
  CC 58 — play, CC 59 — bypass, CC 70 — filter.
  Назначения CC 1/7 относятся к этой настольной версии.
  Модель оригинального звукового устройства целиком не восстановлена;
  точные границы переноса указаны в PORT_STATUS.txt.

Командная строка
  cargo run --release -- demo output.wav --seconds 16 --builtin 1
  cargo run --release -- render input.wav output.wav --seconds 30
  cargo run --release -- render input.wav output.wav --preset halo.sad.json
  cargo run --release -- inspect evilpet1p63.fw
  cargo run --release -- serve --port 3214 --no-open
  cargo run --release -- serve --no-audio

WAV: integer PCM до 32 бит и float32, 1–2 канала. В панели максимальный
размер входного файла 128 MB; рендер 0.1–120 секунд. CLI пишет результат
потоково и поддерживает до часа. Экспорт: stereo float32 WAV, 48 kHz
для CLI, частота аудиоустройства для панели.

Сборка и проверки
  cargo test --workspace
  cargo clippy --workspace --all-targets -- -D warnings
  cargo fmt --all -- --check
  bash rust/scripts/package_macos.sh

На Linux нужны системные библиотеки ALSA; macOS использует CoreAudio
и CoreMIDI. Сборка для Windows/Linux в этой сессии не проверялась.

Код
  src/dsp/       Зерна, сэмплы, модуляция, эффекты.
  src/tables.rs  Восстановленные таблицы и формулы.
  src/audio.rs   DSP-поток и неблокирующая очередь к CoreAudio/CPAL.
  src/midi.rs    MIDI-парсер и подключение устройств.
  src/performance.rs  Hold, арпеджиатор и секвенсор по аудиочасам.
  src/matrix.rs  Источники и назначения матрицы модуляций.
  src/radias_delay.rs  Таблицы времени и частот RADIAS.
  src/server.rs Локальная панель и офлайн-рендер.
  assets/        19464 байта таблиц из предоставленной версии 1.63.
  tests/         Проверки математики, образов, MIDI, аудио и WAV.

Исходные файлы прошивок не изменяются.
